# Unstable Core — Windows Standalone Release

> **A 2D sci-fi action platformer where you control a combat automaton with a critical core malfunction. Energy continuously surges toward meltdown, forcing you to balance aggressive combat, precision parrying, mobility boosts, and your drone companion to survive and reach the exit.**

**Creator:** A.P.S Sowgandh  
**Roll No:** CS25B2030  
**Engine:** Unity (URP 2D) | **Language:** C#  

---

## ⚡ Game Concept & Core Pressure

In **Unstable Core**, time is literally your enemy. 
- Your internal energy core constantly charges toward capacity.
- If your **Energy reaches 100**, catastrophic **Core Meltdown** triggers, resulting in instant death.
- Engaging in combat, using boosts, and deploying your drone companion allows you to dissipate heat, regain health, and maneuver past lethal platform hazards.

## 🕹️ Controls

| Key | Action | Description |
| :---: | :--- | :--- |
| `A` / `D` | **Move Left / Right** | Responsive horizontal platforming movement |
| `Space` | **Jump** | Vertical clearance over obstacles and hazards |
| `J` | **Attack** | Melee blade strikes to damage enemies |
| `K` | **Block / Parry** | Precision timing parry to deflect incoming attacks |
| `E` | **Speed Boost** | Temporary surge in traversal velocity |
| `Q` | **Attack Boost** | Amplified melee damage output |
| `R` | **Jump Boost** | Increased vertical leap height |
| `F` | **Drone Ability** | Deploy autonomous companion to restore Health & vent Energy |

---

## 🎮 How to Play

1. **Defeat Enemies:** Eliminating patrolling hostiles restores crucial Health.
2. **Vent Energy:** Continually monitor your Energy HUD meter. Never allow it to hit 100.
3. **Deploy Drone Support:** Trigger your drone (`F`) to simultaneously recover hitpoints and vent dangerous core energy build-up.
4. **Master Timed Deflects:** Use timed blocks (`K`) to neutralize incoming enemy attacks with Sekiro-inspired parry feedback.
5. **Survive to the Exit:** Traverse moving platforms, avoid stabilization traps, and breach the exit threshold to win.

---

## 🚀 Running the Game

1. Clone or download this repository.
2. Ensure all runtime directories (`Unstable core_Data/`, `MonoBleedingEdge/`, `D3D12/`, `UnityPlayer.dll`) remain in the same folder as the executable.
3. Double-click **`Unstable core.exe`** to launch the game.
